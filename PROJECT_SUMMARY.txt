IMPORTANT NOTES
═══════════════════════════════════════════════════════════════════════════════

  🔐 PRIVACY
     • Repository is PRIVATE (only you can see source code)
     • GitHub Pages is PUBLIC by default (anyone can view the site)
     • You can restrict GitHub Pages access in settings (if available)

  📁 FILE PATHS
     • Use RELATIVE paths in HTML: href="css/styles.css"
     • NOT absolute paths: href="/css/styles.css"
     • This is critical for GitHub Pages to work correctly

  🚀 GITHUB PAGES
     • Site is served from /docs folder
     • index.html is the default landing page
     • Any file in /docs is accessible at the site URL
     • Deployment takes 2-3 minutes after push

  🔑 AUTHENTICATION
     • Use Personal Access Token when pushing (not your password)
     • Create one at: https://github.com/settings/tokens
     • Scope needed: "repo"

COMMON ISSUES & SOLUTIONS
═══════════════════════════════════════════════════════════════════════════════

  Problem: "404 Not Found" on GitHub Pages
  Solution: 
    1. Check docs/index.html exists: ls -la docs/index.html
    2. Check GitHub Pages is enabled: Settings → Pages
    3. Wait 2-3 minutes for deployment
    4. Check Actions tab for errors

  Problem: HTML doesn't render correctly
  Solution:
    1. Fix relative paths (remove leading /)
    2. Check browser console for errors (F12)
    3. Verify CSS/JS files are in correct folders

  Problem: Can't push to GitHub
  Solution:
    1. Use Personal Access Token instead of password
    2. Create one at: https://github.com/settings/tokens
    3. Or use SSH keys (if configured)
