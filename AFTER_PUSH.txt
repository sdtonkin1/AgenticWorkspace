TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Problem: "404 Not Found" on GitHub Pages
Solution:
  1. Check docs/index.html exists
  2. Go to Settings → Pages and verify it's enabled
  3. Wait 2-3 minutes for deployment
  4. Check https://github.com/sdtonkin1/AgenticWorkspace/actions for errors

Problem: HTML doesn't look right on the live site
Solution:
  1. Check your file paths (use relative paths, not absolute)
  2. Open browser console (F12) and check for errors
  3. Verify all CSS/JS/image files are in the right folders

Problem: Can't push to GitHub
Solution:
  1. GitHub CLI is already set up, so just use: git push
  2. It should work without any prompts
  3. If it fails, check your internet connection
