# AgenticWorkspace HTML Prototype

A private HTML prototype hosted on GitHub Pages for SharePoint Modern mockup review.

## About

This repository contains the interactive HTML prototype for the SharePoint Modern Mockup (SKiLNet v15).

## Viewing the Prototype

The prototype is hosted via GitHub Pages at:
`https://sdtonkin1.github.io/AgenticWorkspace/`

## Local Development

To view locally:
1. Clone this repository
2. Open `docs/index.html` in your browser
3. Or use a local server: `python3 -m http.server 8000` then visit `http://localhost:8000/docs/`

## Project Structure

```
docs/
├── index.html          # Main prototype
├── css/               # Stylesheets
├── js/                # JavaScript files
└── assets/            # Images and other assets
```

## Next Steps

1. Download the HTML prototype from SharePoint
2. Place it in the `docs/` folder as `index.html`
3. Add any supporting CSS/JS files to `docs/css/` and `docs/js/`
4. Commit and push to GitHub
5. Enable GitHub Pages in repository settings
